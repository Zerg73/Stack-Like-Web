# 小地图系统 (MiniMap)

## 设计目标

小地图显示**当前视口范围**内的卡牌分布，而非整个地图，提供清晰的局部导航体验。

## 核心特性

| 特性 | 说明 |
|------|------|
| 局部显示 | 只显示当前视口范围内的卡牌 |
| 堆叠数量 | 通过颜色深浅或数字显示堆叠中的卡牌数量 |
| 动态尺寸 | 卡牌点大小根据视口缩放动态调整 |
| 边界检查 | 点击/拖拽定位时限制在地图范围内 |
| 触摸支持 | 支持移动端触摸操作 |
| 视觉反馈 | 拖拽时显示高亮效果 |

## 数据流

```
┌─────────────────────────────────────────────────────────┐
│                    小地图数据流                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  视口状态                                                │
│  ┌──────────────┐                                       │
│  │ translateX   │                                       │
│  │ translateY   │                                       │
│  │ scale        │                                       │
│  └──────┬───────┘                                       │
│         │                                               │
│         ▼                                               │
│  视口范围计算                                            │
│  ┌──────────────┐                                       │
│  │ 视口左下角    │ worldX, worldY                       │
│  │ 视口右上角    │ worldX + viewWidth, worldY + viewHeight │
│  └──────┬───────┘                                       │
│         │                                               │
│         ▼                                               │
│  卡牌过滤                                                │
│  ┌──────────────┐                                       │
│  │ 筛选视口内    │ 只渲染可见卡牌                         │
│  │ 的堆叠       │                                       │
│  └──────┬───────┘                                       │
│         │                                               │
│         ▼                                               │
│  小地图渲染                                              │
│  ┌──────────────┐                                       │
│  │ 卡牌点位置    │ 相对于视口左下角                       │
│  │ 卡牌点大小    │ 根据缩放动态计算                       │
│  │ 堆叠数量      │ 通过透明度或数字显示                   │
│  └──────────────┘                                       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 坐标转换

小地图坐标系统与视口坐标系统一致：

```
小地图原点 = 视口左下角（世界坐标）

小地图上的卡牌位置 = (卡牌世界坐标 - 视口左下角世界坐标) * 小地图缩放比例

小地图缩放比例 = 小地图尺寸 / 视口尺寸
```

## 交互方式

| 操作 | PC端 | 移动端 |
|------|------|--------|
| 点击定位 | 鼠标点击 | 触摸点击 |
| 拖拽导航 | 鼠标拖拽 | 触摸拖拽 |

## 边界处理

点击小地图定位时，需要：
1. 计算目标世界坐标
2. 限制视口平移值在地图边界内
3. 调用 `clampTranslate()` 确保不超出边界
